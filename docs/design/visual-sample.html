Palette

Navy surfaces, bone text, one red for actions and losses, teal for gains. Ratios are WCAG contrast against the page background unless noted.

Activity ramp
One teal hue, five levels: 0, 1, 2–3, 4–6, 7+. Lightness rises at every step, and the dimmest step is 2.25:1 on panels.
Languages
Six colours in a fixed order, safe for colour-blind readers when adjacent, all ≥3:1 on panels. "Other" is grey. Each one is always labelled.

          Decisions behind this sample

          • Red buttons use navy text (5.3:1). White on #FF4655 is 3.4:1, which fails WCAG AA for normal text.
          • Handles are set in Anton without uppercasing, so Benq and jiangly keep their real case. That rules out Bebas Neue, which has no lowercase.
          • Anton has no tabular figures (checked live above), so it is used only for standalone numbers: the current rating, deltas, stat values. Numbers that line up in columns use Barlow or Barlow Condensed, which both have them.
          • Cut corners are painted on background layers, not on the element, so keyboard focus outlines are never clipped.
          • Activity uses one teal ramp. Red stays reserved for actions and rating losses, so a busy month never reads as a bad one.
          • The rating line is bone, the one colour that stays apart from every rank band behind it. Chart text uses text colours, never data colours.
          • Every row says its result three ways: tint, the signed delta, and a Rated / Unrated / Pending label with an icon.
          • The patterns at the right of each row encode the contest type: dense hatching for Div. 1, then wider for Div. 2 and 3, dots for Div. 4, a grid for Educational and chevrons for Global rounds.
